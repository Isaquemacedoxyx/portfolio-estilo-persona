# Portfólio Interativo

Portfólio acadêmico desenvolvido com HTML, CSS e JavaScript puros, inspirado na interface de Persona 3 Reload.

O projeto apresenta uma navegação interativa por seções, com transições visuais, vídeo de fundo e suporte a mouse, toque e teclado. A proposta foi explorar a combinação entre desenvolvimento web e identidade visual, criando uma experiência diferente de um portfólio tradicional.

## Navegação

- `↑` e `↓` — selecionar uma opção no menu.
- `Enter` — abrir a seção selecionada.
- `Esc` — retornar ao menu.
- Mouse e toque — selecionar e navegar pelas opções.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

```text
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    ├── images/
    └── fonts/
```

## Personalização

O conteúdo das seções pode ser atualizado em `index.html`. A identidade visual e os ajustes responsivos estão em `css/style.css`, enquanto a navegação e as interações são controladas por `js/script.js`.

O projeto também inclui suporte à preferência por movimento reduzido, respeitando as configurações de acessibilidade do dispositivo.
